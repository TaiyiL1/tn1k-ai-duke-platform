# ClassIn 授课分析 CSV/XLSX 格式说明

## 一、文件格式概述

ClassIn 平台的「AI 授课分析统计」导出文件格式如下：

- **文件类型**：`.csv` 或 `.xlsx`
- **编码**：UTF-8（CSV 可能带 BOM）
- **表头位置**：第 4 行（前 3 行为统计元信息）
- **Sheet 数量**：XLSX 通常只有 1 个 Sheet

## 二、文件结构（严格格式）

### 第 1 行：标题行
```
AI授课分析统计
```

### 第 2 行：课堂数量
```
课堂数量: 128
```

### 第 3 行：下载时间
```
下载时间: 2026-08-30 14:25:30
```

### 第 4 行：表头（真正的列名行）

| 序号 | 列名 | 说明 | 对应字段 |
|------|------|------|----------|
| 1 | 课堂ID | ClassIn 内部课堂唯一标识 | classin_class_id |
| 2 | 课堂名称 | 课堂的标题名称 | classin_class_name / course_name |
| 3 | 班级ID | 班级唯一标识 | - |
| 4 | 班级名称 | 班级名称 | class_name |
| 5 | 开课时间 | 课程开始时间，格式如 `2026-08-28 09:00:00` | lesson_time |
| 6 | 结束时间 | 课程结束时间 | - |
| 7 | 课堂时长 | 分钟数 | duration |
| 8 | 教师姓名 | 授课老师姓名 | teacher_name |
| 9 | 教师手机号 | 教师手机号 | - |
| 10 | 教师邮箱 | 教师邮箱 | - |
| 11 | 课堂标签 | 课堂的分类标签，如"心理健康"、"趣味阅读"等 | classin_class_label / subject |
| 12 | AI授课分析得分(AI) | ClassIn AI 给出的综合评分（0-100） | classin_ai_score / ai_score |
| 13 | 需关注问题(AI) | ClassIn AI 标注的问题摘要，多个问题用逗号分隔 | classin_ai_issues |
| 14 | 报告链接 | AI 分析报告详情页 URL（可能为空） | classin_report_url / ai_report_url |
| 15 | 回放链接 | 课堂回放视频 URL（可能为空） | classin_replay_url / replay_url |

## 三、自动表头定位规则

由于不同导出版本列顺序可能微调，系统不依赖固定行号，而是**自动扫描前 10 行**，定位同时满足以下条件的行作为表头行：

1. 包含「课堂ID」或「课堂名称」关键字
2. 包含「报告链接」关键字
3. 包含至少 10 个非空列

**匹配优先级**：
1. 完全匹配「课堂ID」→ 最高优先级
2. 包含「课堂名称」+「报告链接」→ 次高优先级
3. 其他组合 → 兜底判断

## 四、科目识别规则

系统自动从以下字段中识别五大学科（心理健康、趣味阅读、美术、趣味科学、音乐）：

| 优先级 | 字段 | 匹配方式 |
|--------|------|----------|
| 1 | 课堂标签 | 完全匹配或包含 |
| 2 | 班级名称 | 包含匹配 |
| 3 | 课堂名称 | 包含匹配 |

**关键词映射表**：

| 科目 | 关键词（不区分大小写） |
|------|----------------------|
| 心理健康 | 心理、心理健康、情绪、情商、社交、性格 |
| 趣味阅读 | 阅读、趣味阅读、语文、绘本、故事、共读 |
| 美术 | 美术、绘画、画画、艺术、手工、折纸 |
| 趣味科学 | 科学、趣味科学、实验、自然、科普、物理、化学 |
| 音乐 | 音乐、歌唱、律动、节奏、乐器、do re mi |

**识别结果字段**：
- `subject`：最终识别出的科目（五选一，识别失败则为空）
- `subject_detected_from`：从哪个字段识别的（`class_label` / `class_name` / `class_name` / `unmatched`）

## 五、报告链接状态

| 状态值 | 含义 | 触发条件 |
|--------|------|----------|
| `pending` | 待读取 | 有报告链接，尚未读取 |
| `fetching` | 读取中 | 正在抓取报告内容 |
| `success` | 读取成功 | 成功获取报告文本 |
| `failed` | 读取失败 | 抓取失败（CORS、网络、404 等） |
| `none` | 无报告链接 | 报告链接为空 |

## 六、导入校验规则

1. **最少列数**：至少包含「课堂名称」和「课堂ID」两列，否则判定为无效文件
2. **有效行数**：表头下方有数据的行（去除空行）
3. **重复检测**：以「课堂ID」为去重键，同一批次内重复只保留第一条
4. **空报告链接**：报告链接列空值统一标记为 `none` 状态
5. **分数解析**：AI 分数尝试转为数字，失败则记为 null，分层为「异常课」
